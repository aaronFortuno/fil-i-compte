# Fil que emmarca

Marca pròpia de Fil i compte: un fil dibuixa un quadrat obert amb un petit bucle i emmarca una suma. Inclinació de −12°, extrems arrodonits i verd `#315e4e`.

- `fil-i-compte.svg`: marca de capçalera, transparent i amb el verd fix del web. La inclinació ja forma part del dibuix; no cal girar-lo amb CSS.
- `favicon.svg`: mateixa geometria amb el contorn una mica més gruixut per a 16 px. Verd clar `#9ccab5` quan el navegador indica tema fosc, per conservar el contrast de la pestanya.

Cal conservar els mateixos dos traçats i la mateixa inclinació en totes dues variants. Recursos locals, sense fonts ni dependències externes.
